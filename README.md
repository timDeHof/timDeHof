## What I do

I build product software, developer tools, and AI-assisted workflows with TypeScript and React. Before software, I worked in mechanical design and 3D printing, which still shapes how I approach product development.

## Selected work

- [**shadcn-timeline**](https://github.com/timDeHof/shadcn-timeline): A customizable timeline component for shadcn/ui. 300+ stars, with a [live demo](https://timdehof.github.io/shadcn-timeline/).

- [**honoforge**](https://www.npmjs.com/package/@timdehof/honoforge): Utilities for Hono and `@hono/zod-openapi`, published on npm.

- [**ScanPick**](https://scanpick.cc): Self-hosted wave-picking software for small warehouses. Single binary, with an [iOS companion](https://apps.apple.com/app/scanpick-companion).

- [**myPortfolio**](https://timdehof.dev): My portfolio and the TypeScript/React system behind it. [Source](https://github.com/timDeHof/myPortfolio).

- **Private work**: A job-search MCP server with Docker and Fly deployment, and an agent-first journaling app. Available on request.
